## AI Engineer training: curriculum

Six modules of five weeks each:

1. **Data Analysis with Python**: Python, NumPy, pandas, Polars, Matplotlib, Seaborn, Plotly, regular expressions, web services, OOP, web scraping, time series, statistics, EDA
2. **Applied Machine Learning**: supervised, unsupervised and reinforcement learning, ensemble methods, decision trees, random forests, clustering, feature engineering, missing values, outlier detection, model evaluation, explainable AI
3. **Deep Learning**: TensorFlow, Keras, PyTorch, MLP, CNN, RNN, LSTM, GRU, autoencoders, GANs, transformers, graph neural networks, interpretability, fairness and robustness
4. **NLP & Generative AI**: NLTK, spaCy, TF-IDF, Word2Vec, embeddings, sentiment analysis, NER, BERT, GPT, Hugging Face, prompt engineering, LangChain, Ollama, RAG, vector databases, agentic AI, fine-tuning
5. **Big Data Engineering**: Apache Spark, Apache Airflow, SQL, NoSQL, ETL pipelines, data modeling and indexing
6. **MLOps & Deployment**: Linux essentials, Docker, version control, MLflow, CI/CD, GitHub Actions, unit tests, FastAPI, monitoring, model deployment, portfolio preparation

## Featured project

**[human-evolution-pipeline](https://github.com/HeikoHan72/human-evolution-pipeline)**: a Spark pipeline over 61.6 million variants of the 1000 Genomes data that tests Neandertal candidate alleles in immune genes. Results in PostgreSQL, MongoDB and Neo4j, orchestrated with Airflow, shown in an offline dashboard ([live demo](https://heikohan72.github.io/human-evolution-pipeline/)) and in Apache Superset. Includes tests and CI.
